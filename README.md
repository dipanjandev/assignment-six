# FITLOG - Gym Center Project

## Description

FITLOG is a modern gym training web application designed to help users organize and track their daily workout routines. Functioning like a dedicated fitness to-do list, it allows you to list your gym activities, create a plan for today, and save workouts for later. Navigating to the **My Plan** section provides a complete overview of your scheduled exercises for today or upcoming sessions.

---

## Technologies Used

- **Framework:** Next.js (App Router)
- **Markup & Core:** XHTML / JSX, TypeScript
- **Styling & UI:** Tailwind CSS, DaisyUI
- **Icons:** Custom SVG icons

---

## Key Features

1. **Manage Daily Schedule:** Organize, track, and update your daily gym routine effortlessly.
2. **Today's Plan & Save for Later:** Add exercises directly to today's active workout plan or save them for future sessions.
3. **Interactive Plan Tracker:** View the total number of exercises, estimated time, and calories directly inside the **My Plan** section.
4. **Mark as Done:** Mark completed exercises as done to keep your workout list up to date and track progress.
5. **Next Day Planning:** Save and postpone workouts for tomorrow or upcoming days with a single click.
6. **Responsive Layout:** Optimized interface that works seamlessly across mobile, tablet, and desktop devices.
